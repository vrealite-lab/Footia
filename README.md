# Foot IA — Prototype de démonstration

Application Streamlit en français pour saisir manuellement des statistiques de football et afficher des estimations illustratives.

## Lancer l'application
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Déploiement gratuit
1. Crée un dépôt GitHub et ajoute `app.py` et `requirements.txt`.
2. Sur Streamlit Community Cloud, connecte GitHub.
3. Choisis ce dépôt, puis `app.py` comme fichier principal.
4. Déploie l'application.

## Important
Ce prototype n'est pas connecté à une API live. Les estimations sont des démonstrations simplifiées et ne sont pas calibrées sur des données historiques. Elles ne constituent pas des conseils de pari.
